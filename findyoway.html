FindYoWay

AI-powered navigation for the blind and visually impaired

A cross-platform mobile app that helps visually impaired users navigate independently, combining outdoor GPS routing, indoor floor-plan navigation, real-time obstacle detection, and a Gemini-powered vision assistant that reads signs and answers questions aloud.

Architecture

components

mobile/

Expo (React Native) user-facing app

backend/

Python Flask server that proxies/orchestrates Gemini API calls

dashboard/

React + Vite web dashboard for venues to register floor plans

notableDecisions

On-device vs. cloud AI split: obstacle detection runs on-device (TensorFlow.js + COCO-SSD) for low latency; sign reading and conversational Q&A go through Gemini Vision for deeper reasoning where latency is more tolerable.

API key and prompt logic kept server-side in Flask rather than called directly from the mobile client.

AsyncStorage used for offline caching so the app degrades gracefully without network signal.

Key Features

  • Outdoor GPS navigation
  • Indoor floor-plan navigation
  • Live sign reading via Gemini Vision
  • Real-time obstacle detection
  • Multilingual voice bot
  • SOS / emergency alert

Challenges & Debugging Stories

Latency-critical vs. accuracy-critical tradeoff

Needed obstacle warnings to be near-instant while allowing sign-reading/Q&A to take longer for better accuracy, driving the on-device/cloud AI split.

Offline resilience

Designed caching (AsyncStorage) so navigation doesn't fully break when connectivity drops.
