ExpenseTracker

Native Android expense tracker with budgeting, analytics, and bill-splitting

A native Android app built with Kotlin and Jetpack Compose for tracking expenses, managing budgets, viewing spend analytics, and splitting bills between people, backed by a local Room database using an MVVM architecture.

notableDecisions

Manual dependency wiring via ViewModelFactory classes instead of a DI framework like Hilt, to keep scope simple.

Fully offline-first: all data persisted locally via Room, no remote backend/sync in this version.

Custom Compose Canvas-based pie chart (StatsPieChart) for category-wise spend visualization.

Key Features

  • Expense tracking (add/view/categorize)
  • Budget management
  • Spend analytics with pie chart visualization
  • Bill-splitting between people (ExpenseShare + SplitUtils)
  • Month-based filtering (MonthSelector / MonthPicker)

Challenges & Debugging Stories

Kotlin / Compose Compiler version mismatch

Build failures traced to the Compose Compiler being tightly version-pinned to a specific Kotlin version; resolved by bumping Kotlin from 1.9.22 to 1.9.23 to match Compose Compiler 1.5.11.

AAR metadata check failures

Hit a ':app:checkDebugAarMetadata FAILED' task, typically caused by a dependency's AAR being compiled against a newer Android API level than the project's compileSdk; diagnosed via Gradle debug output and resolved by aligning SDK/dependency versions.
